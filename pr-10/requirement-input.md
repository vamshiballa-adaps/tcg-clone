## Description

PR #9 moved the job to a self-hosted runner so it could reach the local TCG at http://localhost:3000. That needs a runner registered and online on the developer's PC, jq installed there and a fork-approval setting; the job merged with none registered and sat queued.

The simpler fix is to give the local TCG a public address. The endpoint secret TCG_CICD_ENDPOINT_URL then holds a tunnel URL instead of localhost, and the job runs on ubuntu-latest as TCG generated it: "localhost" on a GitHub-hosted runner is the runner itself, which is what made the earlier runs fail with "Failed to connect to localhost port 3000".

The workflow goes back to TCG's generated file (runs-on ubuntu-latest, no runner checks, body sent with curl -d as generated). The only change kept from the local setup is the project link in the last error message (project 16). The header comment and CLAUDE.md spell out that the secret must be a public URL.
